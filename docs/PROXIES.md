# 代理面板与并发出口

打开面板的“代理管理”。账号概览的“代理 / 节点”和“分配出口”也会进入此页。

## 两种模式

- **Clash 节点直接出口**：选择节点并绑定账号。每个节点对应独立本地监听端口，不修改桌面 Clash 的全局选项；不同账号可以同时使用不同节点。
- **Clash → 已导入海外代理**：先选择前置 Clash 节点，再导入长效或动态海外代理。账号实际链路为 Worker → 所选 Clash 节点 → 海外代理 → 目标服务。

节点名称不同不保证公网 IP 不同。使用“检测所选出口”查看实际公网 IP；检测只访问 IP 查询服务，不发送账号 token、签名或店铺请求。检测成功代表代理网络可达，不能代替业务接口验证。

## 导入与绑定

TXT 每行一个 URL（HTTP、SOCKS5）或 `host:port:user:password`。也支持 JSON 数组或 `{"proxies":[...]}`，每项包含 `name` 和 `proxy`。链式海外出口必须有认证信息，前置节点从已配置的 Clash 池选择。

长效代理无需勾选动态刷新。IPFoxy 单独导入并勾选后，继续沿用已有刷新机制及退避规则。重复导入相同代理与前置节点会复用原路线；不会静默覆盖正在使用的路线。

可以在账号表逐项配置，或勾选账号后批量绑定。账号使用哪条路线显示在列表中。账号处于已排队、运行、等待或中断批次时，先停止批次再修改出口，避免正在运行的并发限制与实际路线不一致。绑定只改变网络配置，不清空额度、冷却或签名状态。绑定中的代理不能删除。

代理库存储在数据库的加密配置中，账号会话保存同样的有效路线。列表只显示名称、网关、前置节点、出口检测和绑定账号，不返回代理用户名、密码或 Clash 控制口令。

## 采集

批次总并发和每条路线并发分别控制。多个账号共用同一条路线时共享该路线的并发限制；普通业务请求不增加人为间隔，定制详情沿用同账号 4 秒间隔。a7 刷新使用该账号的同一条路线。

并发数不限制账号池大小。例如 34 个账号、6 路并发、每路 1 个请求时，全部 34 个账号按额度、接口能力和冷却参与轮换；最多同时发送 6 个请求。业务 HTTP 403 按原账号接口冷却规则处理，定制详情触发的全账号休息仍保留；同出口其他可用账号继续领取任务。即使多个账号连续 403，也不据此暂停整个出口或批次，历史 403 不会在重启后额外封锁路线。单个任务保留已有重试次数和退避，所有账号均不可用时按额度/冷却等待。

传输异常仍单独退避，代理 CONNECT 状态与目标业务 HTTP 状态分开记录。403 本身不能区分账号、会话、请求内容和出口的原因，也不能仅凭换号策略断言账号已经失效。显式配置的 IPFoxy 刷新及有限重试保持原规则。其他账号成功不会清除失败账号的接口冷却或用量。

a7 到期时业务先等待真实 report 成功并保存新值，维护失败则退避。a4、b2/b17、请求 trace、已支持的 body 指纹时间随请求更新，a5 与 a2 根据最终请求重算。支持的 periodic 采集缓存按 60 秒续接并联动 a9；不同布局不能强行改为 periodic。显式 request 模式仅刷新已验证的 b8/b9，保留不能续接的 a9 观察。appsession、b7、a3 配套配置、a10 启动随机值同会话保留。Incognia 仅在具备本安装配置并启用 generate 时生成；captured 模式不能称为已自动刷新。参数刷新不保证目标业务接受请求。

从历史批次重新抽样必须生成新任务，不复制旧响应。验收看店铺、主菜单/render 覆盖、营业且可售定制/子菜完整度；闭店、售罄和未到销售时间分别保留记录。出口畅通、任务已启动、HTTP 200 都不能单独证明交付完成。

## 数据库等待

`database_unavailable` 表示任务调度或记账的数据库连接失败，与业务 HTTP 403 分开处理。执行器保留账本和已落盘的响应，按退避时间自动续跑，不再次发送已经取得响应的请求。

领取任务使用独立连接池，避免轮换账号时反复建立 MySQL TLS 连接。每次归还前回滚事务并释放该连接全部命名锁，清理失败则丢弃连接；业务 HTTP 期间仍持有账号/安装互斥锁。连接复用能减少握手次数，不能保证数据库网络永不超时。测速应单列数据库、网络和额度等待时间。

代理传输错误会在 Worker 日志中记录 `business_transport_error`，包含账号/任务编号、异常类型和代理 CONNECT 阶段的 HTTP 状态；不记录原始异常文本或带认证信息的 URL。代理隧道返回的错误与目标业务接口的 HTTP 403 分开统计。公网 IP 检测成功只说明这次检测请求可达，不能据此清除账号冷却或认定业务接口一定正常。
