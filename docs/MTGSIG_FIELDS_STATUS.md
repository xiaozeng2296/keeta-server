# 当前签名字段与边界

本页为当前实现入口；原生偏移和历史对照见 [证据索引](research/README.md)。已恢复密码不代表能够生成新的真实设备画像或保证任意账号通过业务校验。

| 字段 | 来源和续接方式 |
|---|---|
| a0 | 导入的协议版本 |
| a1 | 原生应用配置输入，参与派生；保留原始字节，不当作设备唯一 UUID |
| a2 | HMAC-SHA1 → 表变换/替换 → pass1/pass2，绑定 canonical 请求、Body 前 16,200 UTF-8 字节、完整 payload 和独立签名序号；验证完整 16 字节 |
| a3 | SDK provider 参数，与 salt 配套，shift=(a3+11)%36；不能只改参数数字 |
| a4 | 每次签名的 Unix 秒 |
| a5 | 已采样的设备/采集结构经 zlib 与 RC4 变体加密，序号和已实现生命周期按规则续接 |
| a6 | SDK 状态位集合；已有资源/PIC/完整性证据，未知分支不随意编造 |
| a7 | `/fingerprint/v1/info/report` 成功响应 data.result；业务前按服务端 interval 到期维护并保存结果 |
| a8 | 导入的 DFP；已有服务端 v5/sign 响应可回填。新账号注册执行器不在本仓库 |
| a9 | CRC/base64/CBC/zlib；支持 AES、Twofish、修改 MDS 的 Twofish；需要原始 a1、匹配模式和配置 |
| a10 | `3,N`，N 是 SDK 启动随机值；同会话续接，不逐请求当计数增加 |
| x0 | 当前支持的原生布局为 2；其他布局不据此推定支持 |

| a5 字段 | 已确认含义/处理 |
|---|---|
| b1 | 设备与环境采集子结构；已有值复用，仅改已证时钟/差分校验槽 |
| b2 | 签名序号，出站低32位 |
| b3/b13/b20 | 不同采集阶段的计数，不能都等同业务请求次数 |
| b4/b5/b6 | 包名、应用版本、build |
| b7 | SDK 启动秒；不是逐请求时间 |
| b8/b9 | 采集缓存秒；periodic 模式按已有观察续接，与 a9 已知时钟联动 |
| b10/b11 | SDK 版本信息 |
| b12、b14/b15/b19、b25 | 端/预留/标志槽；具体未知分支保留捕获值 |
| b16 | 三类 SDK 上报次数、调用和 HTTP200 回调相对时间；info/report 用真实维护事件续接，render 使用已验证兼容补齐 |
| b17 | POST 签名前置计数，出站低32位 |
| b18 | SDK userID 为 nil 时的前置计数；仅在该状态明确时推进 |
| b21 | 时间相关槽，保留支持形态的生命周期 |
| b22 | 区域事件历史，距 SDK 启动的累计毫秒；不凭业务请求数生成 |
| b23/b24 | 设备标识槽，随本账号材料保留 |

`mtgsig/signer.py` 实现签名；`collection_cache.py` 实现支持的周期缓存；`fingerprint_refresh.py` 构造上报、合并 b16 事件；`farm/accounts/fingerprint.py` 执行到期维护、计额度并持久化。a7 刷新成功不会自动清除业务接口冷却。

保留 default/legacy 和显式 provider 是为了兼容已验证账号材料。a5 与缓存 a9 可来自不同配置，各自严格识别。不能把未知配置解码失败强行替换成默认值。

尚未实现：完整设备采集、全部原生生命周期、所有 SDK 状态分支和未知版本自动识别。periodic 的 b1.55 仅是已有 CRC 的等长时间差分，其他输入变化时不能据此宣称重新计算正确。
